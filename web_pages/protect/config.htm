📁 SD Card File Access (FTP)

The device SD card is accessible via FTP at ftp://~config_ip~
Username: admin   Password: admin

Browsers no longer support FTP. Use FileZilla (free FTP client): Download FileZilla

In FileZilla: Host ~config_ip~  —  Port 21  —  User admin  —  Pass admin  →  Quickconnect

🔒 HTTPS Certificate

The device uses a self-signed TLS certificate. Access it at: https://~config_ip~

Optional: access by hostname (https://led-o)

Browsers use DNS — not NetBIOS — for HTTPS, so led-o won't resolve automatically. To enable hostname access, add one line to your PC's hosts file: 

~config_ip~   led-o

Hosts file location: C:\Windows\System32\drivers\etc\hosts (requires Administrator).
After adding the entry, https://led-o will work from that PC.

If you change the IP address:

  1. FTP to the device at ftp://~config_ip~ and download scripts/Regenerate-DeviceCert.ps1
  2. Run it on a Windows PC that holds device.key:
    .\Regenerate-DeviceCert.ps1 -IP <new-ip>
  3. Rebuild firmware (make build) and reflash.
  4. Update your hosts file entry and re-import device.crt into your trust store.

⚠ Firmware Update (SD Card Bootloader)

Upload a versioned firmware binary (e.g. v1.0.0_led_o.bin) to the SD card. The file name must end with led_o.bin. On next reboot the bootloader will flash it and restart automatically. Do not power off during the update.

Warning: uploading an invalid binary will brick the device until it is reflashed via debugger.

The file is stored on the SD card as FIRMWARE.BIN (renamed automatically). If FIRMWARE.BIN already exists the upload will be skipped — delete it via FTP first. After a successful flash the file is removed automatically.
