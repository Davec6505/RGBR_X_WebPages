LED_O is an industrial alarm and information display designed for deterministic, real-time communication over Modbus TCP.

It provides 360° visibility with a 128x64 RGB display and supports text, shapes, bitmap assets, and full-screen color fills. The system is optimized for predictable command-to-display response in PLC-driven control and monitoring environments.

LED_O can present numeric process values alongside graphics to improve operator awareness at a glance.

Key Features

  • 360° visibility for real-time process and alarm data.
  • Modbus TCP server interface for PLC and SCADA integration.
  • Text, shapes, bitmaps, and fill effects for clear visual messaging.
  • Configurable bitmap library for application-specific symbols.
  • RGB565 color rendering tuned for bright, readable industrial output.
  • Numeric display support for both integer and real-value presentation.
  • Expandable asset workflow for adding additional bitmap content.

For complete technical details, refer to the LED_O product manual.
