Industrial Alarm and Information Display

LED_O is built for deterministic, real-time communication over Modbus TCP in PLC-driven control systems.

It provides 360° visibility on a 128x64 RGB display and supports text, shapes, bitmap assets, and full-screen color fills for clear operator messaging.

Resolution128 x 64
ProtocolModbus TCP
Color FormatRGB565
Primary UseIndustrial Alarm UI

Key Features

  • 360° visibility: Real-time process and alarm data visible from all sides.
  • PLC and SCADA integration: Modbus TCP server interface for direct control-system connectivity.
  • Visual command set: Text, shapes, bitmaps, and fill effects for high-clarity status messaging.
  • Configurable bitmap library: Application-specific symbol sets for site-level customization.
  • Readable color tuning: RGB565 rendering optimized for bright industrial readability.
  • Numeric data display: Integer and real-value presentation for live process indicators.
  • Expandable asset workflow: Additional bitmap content can be added as project needs grow.

For complete technical details, refer to the LED_O product manual.

PLC control mode: When a PLC or Modbus client actively controls the display, web commands, file uploads, and FTP access are disabled. The amber banner at the top of each page will appear while PLC control is active. These features restore automatically when the PLC releases control.

⚠ Power loss warning: If power is removed while a file upload is in progress, the SD card may be left in a corrupted state. If the device fails to load assets or read configuration after an unexpected power loss, remove the SD card, reformat it as FAT32, and restore the protect/ folder contents from a known-good backup before reinserting.

ℹ Display behaviour during web page load: LED_O is a single-core embedded device. All network communication — the web server, Modbus TCP, and display rendering — shares the same processor. When you browse into this interface, you may notice multiple short pauses in scroll or rotation as the page loads and the browser fires its background status requests. Each pause lasts less than 200 ms and rotation resumes automatically. This is an architectural characteristic of the hardware platform, not a software defect. It has no effect on PLC or Modbus TCP communication, process data integrity, or display content. The web interface is intended for commissioning, configuration, and asset management — not for use alongside time-critical PLC sequences. If uninterrupted display motion is required during a critical operation, close the browser tab beforehand.
