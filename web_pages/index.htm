Industrial Alarm and Information Display

LED_O is built for deterministic, real-time communication over Modbus TCP in PLC-driven control systems.

It provides 360° visibility on a 128x64 RGB display and supports text, shapes, bitmap assets, and full-screen color fills for clear operator messaging.

Resolution128 x 64
ProtocolModbus TCP
Color FormatRGB565
Primary UseIndustrial Alarm UI

Key Features

  • 360° visibility: Real-time process and alarm data visible from all sides.
  • PLC and SCADA integration: Modbus TCP server interface for direct control-system connectivity.
  • Visual command set: Text, shapes, bitmaps, and fill effects for high-clarity status messaging.
  • Configurable bitmap library: Application-specific symbol sets for site-level customization.
  • Readable color tuning: RGB565 rendering optimized for bright industrial readability.
  • Numeric data display: Integer and real-value presentation for live process indicators.
  • Expandable asset workflow: Additional bitmap content can be added as project needs grow.
